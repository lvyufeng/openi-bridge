照任务模板一键开任务的实测记录（2026-10-15）
=============================================

走的路径：openi_get_task_template 取模板 → 按 (compute_source, acc_card_type,
acc_cards_num) 到 /ai_task/creation/required 的实时清单配对 spec →
openi_start_task_from_template 创建 → 轮询状态 → 停止 → 删除。

模板：<uuid>
      "NPU调试任务-MNIST手写数字识别样例"
      job_type=DEBUG  compute_source=NPU  cluster=C2Net
      acc_card_type=ASCEND910  acc_cards_num=1
      repo=OpenIOSSG/OpenI_Cloudbrain_Example  branch=master  boot_file=(空)
      image_id=0b79fed7504c4etrainms22cann7caaicb1
      image_name=mindspore_2_2_cann7_cb2_caai_26
      image_url=<uuid>   <- 实际是内部记录 UUID，不是镜像地址
      数据集=MnistDataset_mindspore (<uuid>)

本账号实时配到的 spec：id=328  acc_card_type=ASCEND910  acc_cards_num=1
      unit_price=2  ai_center_code=cloudbrain2

状态流转：WAITING（约 70 秒）→ RUNNING → stop → STOPPING → del（删除成功）

两点值得记下来：

1. 代码仓用的是模板自带的公开示例仓 OpenIOSSG/OpenI_Cloudbrain_Example，没有自己的仓
   也能开任务，不需要先建仓。
2. 镜像用的是 spec 328 上实测跑通的 image_id（_image_source=verified_image），模板里
   那个 UUID 形态的 image_url 被忽略了——它当镜像地址发下去拉不起来。

删除，账号下没有留下本次实测的任务。
