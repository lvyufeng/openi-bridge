openi_write_repo_file 覆盖写进去的那一行，说明推上去的代码确实被集群检出并执行了，
不是只写进了仓。

收尾：openi_stop_task → openi_delete_task（{"result": null, "ok": true}）
→ DELETE /repos/scratch-repo → 204 → openi_delete_repository

过程中确认平台侧的两个坑（详见根 README「实现说明与已知限制」）：
- DELETE .../contents/{path} 每次都会挂到代理的 60 秒超时（504/502）且不删文件，
  所以没有包成工具；批量提交入口（POST .../contents、POST /git/blobs）都是 404。
- 建仓偏慢（本次约 32 秒），工具默认 180 秒超时；超时不代表失败。
